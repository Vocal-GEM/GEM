## 2025-03-01 - [ARIA Labels for Icon-Only Buttons in Community & Viz Components]
**Learning:** Found multiple instances of icon-only buttons missing ARIA labels (e.g., upvote buttons in `SuccessStories` using `<Heart>`, and mode toggle buttons in `DynamicOrb`). Additionally, the upvote button had visible text within it, but its `aria-label` needs to explicitly include that dynamic value otherwise screen readers lose the context. The upvote button was also missing proper keyboard focus styles (`focus-visible`).
**Action:** When working with dynamic icon buttons (like upvote counters), ensure the `aria-label` contains both the action and the dynamic numeric value (e.g., ``aria-label={`Upvote, ${upvotes} upvotes`}``). Always add `focus-visible` styling to buttons to ensure keyboard users can track their position.
