## 2024-05-22 - Broken Components as Accessibility Blockers
**Learning:** A component with syntax errors (like unclosed tags or duplicate props) is the ultimate accessibility failure because it renders the interface unusable or unpredictable.
**Action:** Before optimizing for screen readers or contrast, ensure the fundamental HTML structure is valid. Automated tools like linters are the first line of defense for accessibility.
