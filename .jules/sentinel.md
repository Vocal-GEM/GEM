## 2025-04-02 - Missing rel="noopener noreferrer" on target="_blank" links
**Vulnerability:** Found an anchor tag using `target="_blank"` without the corresponding `rel="noopener noreferrer"` attribute in `src/components/ui/VoiceDataConsent.jsx`. This can lead to a reverse tabnabbing vulnerability, where the newly opened page gains control of the original page's `window.opener` object.
**Learning:** Developers sometimes forget to include the `rel` attribute when adding external links that open in a new tab, especially if the link appears to point to an internal or "safe" route (like `/privacy-policy`).
**Prevention:** Always verify that any `target="_blank"` attribute is accompanied by `rel="noopener noreferrer"`. Enforce this through linter rules (like `react/jsx-no-target-blank`) if possible, or make it a standard part of code review for UI components.
