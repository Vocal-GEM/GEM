## 2024-05-24 - Layout Thrashing in Canvas Loops
**Learning:** Found that `getBoundingClientRect()` was being called synchronously inside high-frequency `requestAnimationFrame` loops for the `PitchOrb` visualization. This causes severe layout thrashing by forcing the browser to recalculate the layout on every frame. Additionally, caching canvas dimensions requires carefully resetting the scaling context via `ctx.setTransform(1, 0, 0, 1, 0, 0)` before clearing and reapplying `ctx.scale`, as `ctx.restore()` could multiply transforms uncontrollably in a loop.
**Action:** When creating or optimizing canvas loops, always cache dimensions asynchronously using `ResizeObserver` instead of querying the DOM directly in the loop. Always manage transformation matrices explicitly when caching dimensions.
