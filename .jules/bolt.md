## 2024-03-05 - Avoid getBoundingClientRect in Canvas Render Loops
**Learning:** Calling `getBoundingClientRect()` and indiscriminately resetting `canvas.width` and `canvas.height` inside a high-frequency animation loop (like `requestAnimationFrame`) causes severe synchronous layout thrashing. Furthermore, setting `canvas.width` implicitly clears the canvas, causing subtle state loss if not accounted for.
**Action:** Always track dimensions asynchronously using a `ResizeObserver` on the canvas element and store them in a `useRef`. In the render loop, read the cached dimensions from the ref and ensure explicit `ctx.clearRect()` calls are used. Apply this to remaining visualizers like `PitchVisualizer.jsx`.
