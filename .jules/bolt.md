## 2024-10-27 - [React RenderCoordinator Optimization Pattern]
**Learning:** When migrating a high-frequency component from a localized `requestAnimationFrame` loop to the centralized `RenderCoordinator` service, optimizing state updates is critical. While deadbanding (checking `prev === new`) prevents re-renders, generating a unique ID via `useRef(Math.random())` evaluates the random string on *every* render even though it's only assigned once. This introduces unnecessary JS overhead in an otherwise performance-focused refactor.
**Action:** Use React's native `useId()` for generating stable component IDs to prevent unnecessary string evaluations and ensure hydration safety, especially in high-frequency visualization components.
