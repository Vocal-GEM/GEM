## 2024-08-28 - Centralizing Engine Render Loops
**Learning:** Raw `requestAnimationFrame` loops in backend/engine classes (like `AudioEngine`) can break V-sync frame pacing when running concurrently with other React visualization components that might also be using rAF. Also, leaving legacy rAF cleanup code (like `cancelAnimationFrame(this.animationFrameId)`) after refactoring fails code review.
**Action:** When migrating any class to `RenderCoordinator`, ensure all traces of the old `animationFrameId` state initialization and its `cancelAnimationFrame` cleanup blocks are entirely removed to prevent dead legacy code.
